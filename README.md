# 🎓 Student Performance Analysis and Classification Using Python

## 📌 Project Overview

This project focuses on analyzing student performance and predicting a student's final grade based on academic, behavioral, and lifestyle attributes.

The project includes data exploration, visualization, preprocessing, feature selection, and classification using Python.

## 📊 Dataset

The dataset contains **10,000 student records and 15 columns**.

The dataset includes information such as:
- Student Age and Gender
- Study Hours per Week
- Preferred Learning Style
- Online Courses Completed
- Participation in Discussions
- Assignment Completion Rate
- Exam Score
- Attendance Rate
- Use of Educational Technology
- Self-Reported Stress Level
- Time Spent on Social Media
- Sleep Hours per Night
- Final Grade

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 🔍 Key Analysis

- Dataset exploration using `info()`, `shape`, `columns`, and `describe()`
- Missing value analysis
- Duplicate record analysis
- Statistical analysis of numerical variables
- Box plots and histograms
- Scatter plot matrix
- Gender distribution visualization
- Categorical variable encoding
- Feature selection using SelectKBest
- Feature scaling using StandardScaler

## 🤖 Machine Learning

**Logistic Regression** was used to classify students based on their final grade.

The target variable `Final_Grade` was encoded using LabelEncoder, while categorical independent variables were converted using One-Hot Encoding.

## 📈 Model Evaluation

The model was evaluated using:
- Accuracy Score
- Classification Report
- Confusion Matrix
- Precision
- Recall
- F1-Score

**Model Accuracy: 99.92%**

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the Jupyter Notebook in Google Colab or Jupyter Notebook.
3. Keep the CSV dataset in the same working directory.
4. Run the notebook cells sequentially.
